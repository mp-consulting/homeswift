Privacidad

Qué sabe de ti este sitio

Nada que recopile por su cuenta. homeswift.dev es una página estática, más esta: sin cookies, sin analítica, sin formularios, sin cuentas y sin nada cargado desde otro sitio. Tu navegador descarga cada archivo solo desde homeswift.dev, y su política de seguridad lo impone.

Quién lo aloja

El sitio lo sirve GitHub Pages. Para servir las páginas y proteger el servicio, GitHub recibe lo que recibe cualquier servidor web: tu dirección IP, la página pedida, la hora y la descripción de tu navegador, y puede guardarlos en sus registros. Cómo trata GitHub esos datos se explica en GitHub General Privacy Statement y en About GitHub Pages: data collection (en inglés).

Los servidores de nombres del dominio son de Cloudflare. Responden a la consulta de homeswift.dev, como haría una guía telefónica, y no ven las páginas que lees.

Enlaces a otros sitios

La documentación, el código fuente y las versiones están en GitHub. Al seguir un enlace allí, pasas a GitHub, y entonces se aplica su declaración de privacidad.

El software en sí

Homeswift se ejecuta en tu propio equipo y no envía nada a este sitio ni a sus autores. Se comunica con los dispositivos y servicios que configuras; dos veces al día pregunta a GitHub si hay una versión nueva, una petición que solo lleva su número de versión (Buscar actualizaciones, en los ajustes de la interfaz web, la desactiva); y el Asistente, si lo activas, solo se comunica con el proveedor de IA que elijas, tras ocultar lo sensible de lo que envía. El README de cada plugin indica con qué nube habla.
