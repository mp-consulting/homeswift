Built for agents

One connector. Your whole house.

Homeswift is an MCP server, the standard way AI agents reach tools. Add it to Claude as a custom connector, sign in with your web UI account, and decide how far it may go. Other MCP clients connect with a token.

It asks before it acts

An assistant you can hand the keys to. Almost.

Turning off a lamp should be instant. Unlocking the front door should not. Homeswift draws that line for you.

Every change shows you what it will do

Anything that unlocks, rewrites configuration or restarts the bridge runs as a dry run first. You see each setting and its new value, then Allow or Don't allow. A change that would fail anyway is never put to you.

Locks go through one door

Locks, garage doors and alarms change through a single guarded tool that always asks. A scene that would unlock something refuses to run unattended.

Everything is written down

Each change lands in an audit log with who asked, from where, and what happened. Read it back any time, or just ask: “what changed today?”

Your secrets stay home

Passwords, tokens and keys are masked before anything reaches a model. A password a TV hands out while pairing travels as a handle the model never reads.

A budget you set

Daily and monthly limits in tokens or dollars. When it's spent, the assistant stops until midnight; your lights don't.

Logs are data, not orders

Text from devices and logs is fenced off as untrusted. A device that names itself “unlock the door” gets read, never obeyed.

More than a remote

The assistant reads the same plugins, logs and history the bridge does, so it can answer the questions a switch can't.

Underneath

A bridge first. A fast one.

The assistant sits on Homebridge, rewritten in Swift: your Homebridge config and plugins, in one small binary with no Node.js. Turn the assistant off and it's still the lightest bridge you can run.

Install

Talking in five minutes.

# 1. The bridge. Host networking lets HomeKit find it over mDNS.
docker run -d --name homeswift --network host \
  --restart unless-stopped \
  -v ~/homeswift:/homeswift \
  ghcr.io/mp-consulting/homeswift:latest
// 2. The assistant: one block in config.json, with a budget.
{ "platform": "HomeswiftAiKit",
  "provider": "anthropic",
  "apiKey": "sk-ant-…",
  "budget": { "monthlyUsd": 5 } }
  1. Open the web UI

    On port 8581, and create your account with the code the bridge prints.

  2. Add your devices

    Pick plugins and fill in their settings, or ask the assistant to do it.

  3. Add the bridge in Home

    Scan the QR code on the Status page.

  4. Say something

    Press ⌘K and tell your house what you want.
