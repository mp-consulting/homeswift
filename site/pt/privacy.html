Privacidade

O que este site sabe de quem o visita

Nada que o próprio site recolha. O homeswift.dev é uma página estática, mais esta: sem cookies, sem estatísticas, sem formulários, sem contas e nada carregado de outro site. O navegador obtém cada ficheiro apenas a partir de homeswift.dev, o que a política de segurança do site impõe.

Quem o aloja

O site é servido pelo GitHub Pages. Para entregar as páginas e proteger o serviço, o GitHub recebe o que qualquer servidor web recebe: o endereço IP, a página pedida, a hora e a descrição do navegador, e pode guardá-los nos seus registos. O tratamento desses dados pelo GitHub está descrito em GitHub General Privacy Statement e em About GitHub Pages: data collection (em inglês).

Os servidores de nomes do domínio são da Cloudflare. Respondem à consulta de homeswift.dev, como faria uma lista telefónica, e não veem as páginas lidas.

Ligações para outros sites

A documentação, o código-fonte e as versões estão no GitHub. Seguir uma ligação para lá leva ao GitHub, cuja declaração de privacidade passa então a aplicar-se.

O software em si

O Homeswift corre na máquina de quem o instala e não envia nada a este site nem aos seus autores. Contacta os dispositivos e serviços configurados; duas vezes por dia pergunta ao GitHub se saiu uma versão nova, um pedido que leva apenas o número da versão (Check for updates, nas definições da interface web, desativa-o); e o Assistente, se for ativado, contacta apenas o fornecedor de IA escolhido, depois de ocultar o que é sensível no que envia. O README de cada plugin indica com que nuvem comunica.
