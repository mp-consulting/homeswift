Confidentialité

Ce que ce site sait de vous

Rien qu'il collecte lui-même. homeswift.dev, c'est une page statique et celle-ci : pas de cookies, pas de statistiques, pas de formulaires, pas de comptes, et rien de chargé depuis un autre site. Votre navigateur récupère chaque fichier depuis homeswift.dev uniquement, ce que sa politique de sécurité impose.

Qui l'héberge

Le site est servi par GitHub Pages. Pour délivrer les pages et protéger le service, GitHub reçoit ce que reçoit tout serveur web : votre adresse IP, la page demandée, l'heure et la description de votre navigateur, et peut les conserver dans ses journaux. Le traitement de ces données par GitHub est décrit dans le GitHub General Privacy Statement et dans About GitHub Pages: data collection (en anglais).

Les serveurs de noms du domaine sont ceux de Cloudflare. Ils répondent quand on cherche homeswift.dev, comme le ferait un annuaire, et ne voient pas les pages que vous lisez.

Liens vers d'autres sites

La documentation, le code source et les versions sont sur GitHub. Un lien vers eux vous emmène chez GitHub, dont la déclaration de confidentialité s'applique alors.

Le logiciel lui-même

Homeswift tourne sur votre propre machine et n'envoie rien à ce site ni à ses auteurs. Il contacte les appareils et les services que vous configurez ; deux fois par jour, il demande à GitHub si une nouvelle version est sortie, une requête qui ne contient que son numéro de version (Rechercher les mises à jour, dans les réglages de l'interface web, la désactive) ; et l'Assistant, si vous l'activez, ne contacte que le fournisseur d'IA de votre choix, après avoir masqué ce qui est sensible dans ce qu'il envoie. Le README de chaque plugin indique à quel cloud il parle.
