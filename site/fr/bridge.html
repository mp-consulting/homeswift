Homebridge, réécrit en Swift

Tous vos appareils, dans l'app Maison.

Homeswift fait entrer dans HomeKit les lampes, climatiseurs, caméras et serrures qu'Apple n'a jamais certifiés. Un seul petit binaire fait tourner votre config et vos plugins Homebridge, sans Node.js ni npm, et consomme moins de 10 MB au repos.

Votre config Homebridge, telle quelle

Homeswift lit un config.json au format Homebridge. Les plugins gardent leurs noms de plateforme et d'options, les ponts enfants fonctionnent de la même façon, et chaque modification est vérifiée d'après le schéma du plugin avant d'être enregistrée.

Caméras et sonnettes

Vidéo en direct et instantanés via SRTP, enregistrement HomeKit Secure Video, audio bidirectionnel et sonnerie de la sonnette, avec FFmpeg pour l'encodage.

Une interface web à l'image de Maison

Chaque accessoire est un widget sur un mur que vous organisez. État, plugins, config, journaux et sauvegardes sont juste à côté, derrière vos propres comptes, avec l'authentification à deux facteurs si vous le souhaitez.

Un Assistant, si vous en voulez un

Demandez pourquoi une lampe ne répond plus, faites expliquer un journal ou recevez un résumé quotidien. Facultatif, avec un budget, et tout ce qui est sensible est masqué avant d'atteindre un fournisseur.

Votre maison dans Claude et d'autres apps d'IA

Un serveur MCP que claude.ai et les apps Claude ajoutent comme connecteur : vous vous connectez avec votre compte de l'interface web et choisissez ce qu'il peut faire. Toute action destructive demande d'abord confirmation, chaque modification est journalisée, et serrures, portes de garage et alarmes passent par un seul outil protégé.

Installation

Opérationnel en cinq minutes.

# amd64 et arm64. Le réseau de l'hôte permet à HomeKit de trouver le pont par mDNS.
docker run -d --name homeswift --network host \
  --restart unless-stopped \
  -v ~/homeswift:/homeswift \
  ghcr.io/mp-consulting/homeswift:latest
# DSM 7.0 ou ultérieur, modèles x86_64 et aarch64. Pas besoin de Docker.
# 1. Téléchargez le .spk de votre modèle depuis la dernière version :
https://github.com/mp-consulting/homeswift/releases/latest
# 2. Centre de paquets › Installation manuelle, puis suivez l'assistant.
# 3. Ouvrez Homeswift depuis le menu principal de DSM.
// Package.swift : construisez votre propre accessoire sur la bibliothèque.
dependencies: [
    .package(url: "https://github.com/mp-consulting/homeswift.git",
             from: "0.12.0"),
]
  1. Ouvrez l'interface web

    Sur le port 8581 de la machine où tourne le pont.

  2. Créez votre compte

    Avec le code de configuration que le pont affiche au démarrage.

  3. Ajoutez des plugins

    Choisissez-les sur la page Plugins et remplissez leurs réglages.

  4. Ajoutez le pont dans l'app Maison

    Scannez le code QR de la page État, ou saisissez le code à 8 chiffres.

Pour les développeurs

Une lampe en vingt lignes.

  • Les 73 services et 252 caractéristiques que connaît HomeKit, avec leurs unités, plages et valeurs valides.
  • La concurrence de Swift 6 : les handlers sont async, et une erreur levée se traduit par « Pas de réponse » dans l'app Maison.
  • Définissez une valeur quand l'appareil change, et chaque app Maison abonnée se met à jour.
import Homeswift

let light = Service(.lightbulb, name: "Desk Lamp",
                    optional: [.brightness], isPrimary: true)

light.characteristic(.on).onWrite(changesOnly: true) { value in
    try await lamp.setPower(value.boolValue ?? false)
}

let accessory = Accessory(
    id: "desk-lamp", name: "Desk Lamp",
    manufacturer: "Acme", model: "L1",
    category: .lightbulb, services: [light])

let server = try HAPServer(bridge: bridge, accessories: [accessory],
                           storage: FileStorage(name: "my-bridge"))
print("Setup code:", server.setupCode)  // 1234-5678
try await server.run()
