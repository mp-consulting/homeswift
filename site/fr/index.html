Conçu pour les agents

Un connecteur. Toute votre maison.

Homeswift est un serveur MCP, le standard qui permet aux agents IA d’accéder à des outils. Ajoutez-le à Claude comme connecteur personnalisé, connectez-vous avec votre compte de l’interface web et décidez jusqu’où il peut aller. Les autres clients MCP se connectent avec un jeton.

Connecter Claude

Claude demande à utiliser votre pont en tant que alex.

RefuserAutoriser

  1. Mettez l’interface web en ligne

    En HTTPS, sous un nom de domaine : Cloudflare Tunnel, Tailscale Funnel ou votre propre proxy inverse.

  2. Ajoutez le connecteur

    Dans Claude, Paramètres › Connecteurs › Ajouter un connecteur personnalisé, avec https://home.example.com/mcp. Pas d’identifiant client à copier : Claude s’enregistre tout seul.

  3. Connectez-vous et choisissez

    Lecture, Contrôle ou Administration, jamais plus que ce que votre compte autorise. Le connecteur vous suit dans les apps Claude de votre téléphone.

Il demande avant d’agir

Un assistant à qui confier les clés. Ou presque.

Éteindre une lampe doit être immédiat. Déverrouiller la porte d’entrée, non. Homeswift trace cette limite pour vous.

Chaque changement vous montre d’abord ce qu’il va faire

Tout ce qui déverrouille, réécrit la configuration ou redémarre le pont passe d’abord par un essai à blanc. Vous voyez chaque réglage et sa nouvelle valeur, puis choisissez Autoriser ou Ne pas autoriser. Un changement qui échouerait de toute façon ne vous est jamais proposé.

Les serrures passent par une seule porte

Serrures, portes de garage et alarmes ne changent d’état que par un seul outil protégé, qui demande toujours votre accord. Une scène qui déverrouillerait quelque chose refuse de s’exécuter sans vous.

Tout est consigné

Chaque changement est inscrit au journal d’audit : qui l’a demandé, d’où, et ce qui s’est passé. Relisez-le quand vous voulez, ou demandez simplement : « Qu’est-ce qui a changé aujourd’hui ? »

Vos secrets restent à la maison

Mots de passe, jetons et clés sont masqués avant que quoi que ce soit n’atteigne un modèle. Le mot de passe qu’une TV fournit pendant le jumelage circule sous forme de référence que le modèle ne lit jamais.

Un budget que vous fixez

Limites quotidiennes et mensuelles, en jetons ou en dollars. Une fois le budget épuisé, l’assistant s’arrête jusqu’à minuit ; vos lumières, non.

Les journaux sont des données, pas des ordres

Le texte venu des appareils et des journaux est cloisonné et traité comme non fiable. Un appareil qui se nomme « déverrouille la porte » est lu, jamais obéi.

Dans Claude

Ajoutez Homeswift comme connecteur dans claude.ai et les apps Claude. Vous vous connectez avec votre compte de l’interface web et choisissez ce qu’il peut faire : lire, contrôler ou administrer.

Dans un terminal

ask pour une question, explain pour une erreur, diagnose pour un journal, ou le digest du jour. Envoyez-y directement la sortie de journalctl.

Sous le capot

Installer

Cinq minutes, et vous lui parlez.

# 1. Le pont. Le réseau de l’hôte permet à HomeKit de le trouver par mDNS.
docker run -d --name homeswift --network host \
  --restart unless-stopped \
  -v ~/homeswift:/homeswift \
  ghcr.io/mp-consulting/homeswift:latest
// 2. L’assistant : un bloc dans config.json, avec un budget.
{ "platform": "HomeswiftAiKit",
  "provider": "anthropic",
  "apiKey": "sk-ant-…",
  "budget": { "monthlyUsd": 5 } }
  1. Ouvrez l’interface web

    Sur le port 8581 ; créez votre compte avec le code affiché par le pont.

  2. Ajoutez vos appareils

    Choisissez des plugins et remplissez leurs réglages, ou demandez à l’assistant de le faire.

  3. Ajoutez le pont dans Maison

    Scannez le code QR de la page État.

  4. Dites quelque chose

    Appuyez sur ⌘K et dites à votre maison ce que vous voulez.
