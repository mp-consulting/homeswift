Privacy

What this site knows about you

Nothing it collects itself. homeswift.dev is one static page and this one: no cookies, no analytics, no forms, no accounts, and nothing loaded from another site. Your browser fetches every file from homeswift.dev only, which its security policy enforces.

Who hosts it

The site is served by GitHub Pages. To deliver the pages and protect the service, GitHub receives what any web server receives: your IP address, the page asked for, the time and your browser's description, and it may keep them in its logs. GitHub's handling of that data is described in the GitHub General Privacy Statement and in About GitHub Pages: data collection.

The domain's name servers are Cloudflare's. They answer the lookup of homeswift.dev, as a phone book would, and do not see the pages you read.

Links to other sites

The documentation, the source code and the releases are on GitHub. Following a link there takes you to GitHub, whose privacy statement then applies.

The software itself

Homeswift runs on your own machine and sends nothing to this site or to its authors. It reaches the devices and services you configure; twice a day it asks GitHub whether a newer release is out, a request that carries only its version (Check for updates, in the web UI's settings, turns that off); and the Assistant, if you turn it on, reaches only the AI provider you choose, with what it sends redacted first. Each plugin's README says which cloud it talks to.
