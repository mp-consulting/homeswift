Troubleshooting
Token expired or invalid
Revoke access on the Authentication tab, then sign in again on Add accessories.
Authentication flow issues
Check that the redirect URI in the portal matches exactly, bind the callback server to 0.0.0.0, check the firewall for the callback port.
Device not appearing
Check the log, check the device in the Onecta app, check the hidden devices on Settings › Devices.
