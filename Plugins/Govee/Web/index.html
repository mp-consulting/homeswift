Documentation

The options are described in the plugin's README; the connections are tried in this order:

  • LAN: local network control (faster, works without internet), for models with the LAN API turned on in the Govee app.
  • AWS IoT: real-time control through Govee's cloud (requires credentials).
  • BLE: Bluetooth control for nearby devices (requires a Bluetooth adapter).
Changes are kept once you save.
